# Kontier RI — Revenue Intelligence Studio

**An open-source, agent-native analytics studio where you and your AI agent build
revenue dashboards together — on the same canvas, at the same time.**

Built on [WebMCP](https://webmachinelearning.github.io/webmcp/): the page exposes
~24 structured tools to your browser agent (ChatGPT in-app browser, Chrome 149+).
The agent queries your data and drafts tiles; you drag, restyle and steer. Your
raw data never leaves the browser — SQL runs locally via DuckDB-WASM.

> Status: under active development for the WebMCP Challenge (Sep 2026).

See [docs/PLAN.md](docs/PLAN.md) for architecture and roadmap.
